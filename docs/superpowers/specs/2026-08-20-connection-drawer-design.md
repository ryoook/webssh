# 右侧连接抽屉设计

## 目标

将顶部连接表单与工具区移除，改为从页面右侧打开的连接抽屉。用户可以在抽屉中维护连接配置，并通过点击配置新建终端 Tab。

## 页面布局

- 终端 Tabs 占据完整页面，不再保留顶部连接表单。
- 页面右侧固定一个“连接”悬浮按钮。
- 点击按钮打开右侧抽屉；桌面端宽度约 320px，小屏幕下自适应至不超过视口宽度。
- 抽屉顶部提供“新建”“管理”“文件”“语言”操作，下方展示连接列表。

## 连接管理

- 点击“新建”打开连接表单，字段包括主机、端口、用户名、认证方式以及密码或私钥。
- 保存只写入连接列表，不立即发起 SSH 连接。
- 每条连接记录拥有独立 ID，允许同一主机保存不同端口或账号。
- 点击“管理”切换管理模式；管理模式下每条记录显示编辑和删除按钮。
- 编辑复用连接表单并覆盖原记录。
- 删除前显示二次确认。

## 打开连接

- 非管理模式下，点击连接项将该配置写入当前 SSH 状态。
- 随后创建新的终端 Tab，并自动关闭连接抽屉。
- 每次点击都新建 Tab，不复用已有连接 Tab。
- 缺少密码或私钥时仍创建连接表单供补充，不直接创建空白终端。

## 数据存储与兼容

- 连接列表继续保存在浏览器 `localStorage`。
- 读取现有 `sshList` 时为缺少 ID 的旧记录补充 ID，保持已有数据可用。
- 保存与编辑统一通过 Vuex mutation 更新内存状态和 `localStorage`。
- 是否持久化密码沿用后端返回的 `savePass` 配置；不允许保存密码时，仅保存其余连接信息。

## 组件划分

- `App.vue`：终端主体、右侧入口和抽屉的整体布局，协调抽屉与 Tabs。
- 新连接抽屉组件：工具区、连接列表、管理状态以及新建/编辑对话框。
- `Header.vue`：不再承担顶部连接表单职责；相关文件与语言操作迁移后删除其页面引用。
- `Tabs.vue`：保留现有新建 Tab 能力，由抽屉选中连接后调用。
- Vuex：增加连接列表的新增、更新、删除和旧数据迁移逻辑。

## 校验与错误处理

- 主机、端口、用户名和认证凭据必填。
- 端口必须为 1–65535 的整数。
- 删除操作必须确认。
- 表单校验失败时不关闭对话框、不修改连接列表。
- 私钥继续支持文本输入与文件选择。

## 验证

- 新建连接保存后出现在列表中，但不打开 Tab。
- 编辑连接后列表和本地存储同步更新。
- 删除确认后记录消失，取消时记录保留。
- 点击列表项创建新的终端 Tab 并关闭抽屉。
- 同一连接连续点击两次会创建两个独立 Tab。
- 旧版 `sshList` 能正常迁移和展示。
- 文件管理与语言切换在抽屉中仍可使用。
